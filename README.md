# AdTravelz

AdTravelz is a dynamic and user-friendly travel agency website designed to help travelers explore destinations, book travel packages, and customize their itineraries. The platform allows users to explore popular destinations with detailed descriptions and images, browse and book travel packages, customize itineraries according to their preferences, and search and filter destinations based on categories such as budget, location, and duration. The application is built using React.js, Tailwind CSS, HTML, CSS, and JavaScript for the frontend, Node.js and Express.js for the backend, and MongoDB for data storage. Axios is used for API calls, React Router is used for navigation, and Postman is used for API testing. The project is organized into separate `client` and `server` directories for the frontend and backend respectively. To run the project locally, clone the repository using `git clone https://github.com/deepanjaliw/AdTravelz.git`, install the required dependencies in both the `client` and `server` directories using `npm install`, start the frontend and backend using `npm start`, and access the application through the local development URL.
